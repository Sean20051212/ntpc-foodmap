## 4. 結構性建議（風險高，需 stakeholder 決策）

### 4.1 「小吃∕熱炒」拆分
**現況**：297 家（43%），疑似 import default。
**建議**：拆為「夜市小吃」（攤車/小份量）+「熱炒台菜」（合菜/啤酒屋）。
**風險**：需 reclassify 297 家、規則難以自動化，建議**保持現狀**直到有人工 review 預算。

### 4.2 「冰品飲料」是否拆分
**現況**：100 家。用戶曾提到「飲料與冰品應該分開」。
**評估**：冰品（剉冰、豆花、雪花冰）與飲料（手搖、現榨）使用情境的確不同（夏天 vs 全年、堂食 vs 外帶）。
**建議**：**保持合併**。理由：
- 100 家是合理規模，拆完每邊還是 30–70
- 多數店家其實兩者都賣（剉冰店常有手搖飲）
- 拆完仍需重新標記 100 家，effort/value 比不高

### 4.3 「異國料理」是否拆分
**現況**：80 家。涵蓋義式、法式、韓式、泰式、印度、越南、土耳其...
**評估**：確實太寬，但若拆成各國料理會出現很多 5~10 家的細 tag（違反 professor「不過細」原則）。
**建議**：**保持合併**，未來若資料量達 200+ 再考慮二級分類（例：歐式 / 亞洲 / 中東）。
